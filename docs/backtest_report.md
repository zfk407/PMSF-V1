# ZHIHUI-DLT 回测验证分析报告
## 逐思路有效性检验 · 双色球 / 大乐透

> 版本：2026-08-26 · 基于真实数据 walk-forward 滚动回测
> 方法：每个思路独立对号码评分 → 排序 → 与实际开奖对比 Top10/Top15 命中数、平均排名
> 基准：随机期望（双色球 Top10=1.82、大乐透 Top10=1.43）

---

## 一、回测数据与方法

| 项目 | 大乐透 | 双色球 |
|---|---|---|
| 数据来源 | 本地库 2872 期真实（07001~26095） | 福彩官网 API 120 期真实 |
| 回测窗口 | 40 期 + 80 期两轮 | 25 期 + 40 期两轮 |
| 方法 | 逐期 walk-forward（只用当期之前数据） | 同左 |
| 思路数 | 9 个 | 15 个 |

核心判定：**以 Top10 命中数相对随机基准的增量 Δ 衡量信息量**。彩票是独立随机事件，任何思路都不可能"预测"开奖；本报告回答的是"哪些信号相对更有信息量、哪些是纯噪声/有害"，以及如何据此重构系统。

## 二、双色球逐思路结论（120期真实）

### 2.1 结果汇总（ΔTop10 均值，两轮回测）

| 思路 | 25期Δ | 40期Δ | 判定 |
|---|---|---|---|
| **miss（遗漏回补）** | — | **+0.18** | ✅ 相对有效 |
| **blue_boost（蓝补红）** | +0.22 | +0.13 | ✅ 唯一两轮均正 |
| **transition（过渡号）** | +0.18 | +0.05 | ✅/➖ 微效 |
| **freq_line（同线频率）** | +0.06 | -0.02 | ➖ 中性 |
| extension（组外拓展） | -0.06 | -0.02 | ➖ 中性 |
| tail_law（尾数定律） | +0.02 | -0.05 | ➖ 中性 |
| combo（多信号叠加） | — | +0.00 | ➖ 中性 |
| freq100（全量频率） | -0.06 | -0.17 | ❌ 无效 |
| bayes（同线贝叶斯） | -0.18 | -0.17 | ❌ 无效 |
| group_hot（组热度） | -0.18 | -0.15 | ❌ 无效 |
| rebound（隔期返点） | -0.18 | -0.12 | ❌ 无效 |
| **pengpai_prior（彭湃整体先验）** | -0.26 | -0.22 | ❌ 负效 |
| markov（转移概率模型） | -0.22 | — | ❌ 负效 |
| temporal（EWMA时序） | -0.26 | — | ❌ 负效 |
| graph（图网络） | -0.14 | — | ❌ 负效 |
| ml（XGB+CatBoost） | -0.02 | — | ➖ 中性 |
| fused（全模型融合） | -0.14 | — | ❌ 负效 |
| **entangle（纠缠Lift）** | **-0.42** | **-0.27** | ❌❌ 两轮最差 |

### 2.2 分条结论

**✅ 有用（保留并加权）**
1. **遗漏回补（miss）**——冷号连出断档后回补，是信息量最大的信号。40期 +0.18。建议：作为核心排序依据之一。
2. **蓝补红（blue_boost）**——蓝球出号→同号红球点位计数+1，改变组冷热。两轮均正（+0.22/+0.13），是唯一稳定正贡献的彭湃规则，说明"蓝代红"机制捕捉到了真实联动信息。建议保留。
3. **过渡号（transition）**——主/副过渡号（31/13）附近号码倾向出号，25期 +0.18。建议保留低权重。

**➖ 中性（意义不大，可降权）**
4. 同线频率、组外拓展、尾数定律、多信号简单叠加——均围绕随机波动。同线频率略优于全量频率（说明**双线公理有微弱正贡献**），但不显著。

**❌ 无效/负效（砍掉或大幅降权）**
5. **纠缠 Lift（entangle）**——两轮最差（-0.42/-0.27），是系统里**危害最大**的彭湃因子。"Lift≥1.25 判定纠缠热组"在真实数据上不仅无用反而显著拉低命中。建议：删除或改为仅作展示、禁止进入评分。
6. **彭湃整体先验（pengpai_prior）**——贝叶斯×规则乘积（组热度+拓展+返点+蓝补红+过渡号+周期+尾数+配对一堆因子相乘）两轮均 -0.22 左右。**问题根源：把多个微效/无效因子相乘，噪声叠加放大，最终反噬**。建议：只保留被验证有效的 miss/blue_boost/transition 三个因子，删掉纠缠、组热度、返点。
7. **全量频率（freq100）、贝叶斯（bayes）、组热度（group_hot）、隔期返点（rebound）**——负效或无效。
8. **高阶算法模型**——Markov（-0.22）、Temporal（-0.26）、Graph（-0.14）在 25 期样本上均负效；**全融合（fused）反而比单一有效信号更差（-0.14）**。结论：**复杂度没有换来预测力，双色球数据量（120期）根本不足以训练这些模型，它们只是把噪声当规律。**

### 2.3 蓝球
- freq_only 命中率 4.0%、freq+遗漏加权 0.0%，均低于随机基准 6.25%。
- **结论：蓝球预测在现有数据上无效**，建议蓝球只做"结构参考"（大小/奇偶/尾分布），不做号码预测。

## 三、大乐透逐思路结论（2872期真实）

### 3.1 结果汇总（ΔTop10 均值，两轮回测）

| 思路 | 40期Δ | 80期Δ | 判定 |
|---|---|---|---|
| **freq100（近100期频率）** | +0.17 | +0.09 | ✅ 相对有效 |
| **state_bias（三态偏置）** | +0.12 | +0.09 | ✅ 相对有效 |
| freq_line（同线频率） | -0.00 | +0.07 | ➖ 中性 |
| miss（遗漏） | -0.03 | +0.07 | ➖ 中性 |
| rebound（隔期返点） | +0.07 | +0.03 | ➖ 中性 |
| graph（图纠缠） | +0.07 | +0.03 | ➖ 中性 |
| graph_emb（谱嵌入） | +0.02 | +0.03 | ➖ 中性 |
| combo（多信号叠加） | -0.03 | -0.04 | ❌ 负效 |

### 3.2 分条结论

**✅ 有用（保留并加权）**
1. **近100期频率（freq100）**——热号延续，两轮稳定 +0.09~+0.17。是大乐透**最强单信号**。
2. **三态偏置（state_bias）**——纠缠热态偏热号、终止冷态偏冷号回补、拓展态偏扩散。两轮稳定 +0.09~+0.12。**"先判状态、再定选号偏向"的彭湃核心思路被实证支持**。

**➖ 中性**
3. 双线拆分（freq_line vs freq100 对比：双线频率略低于全量，说明**大乐透的双线公理没有增益**，与双色球相反）、遗漏、隔期返点、图纠缠、谱嵌入——均在随机噪声内。

**❌ 无效/负效**
4. **多信号叠加（combo）**——把频率+遗漏+返点相加后反而 -0.04，比单信号差。再次印证：**叠加无效信号会稀释有效信号**。

### 3.3 系统级回测（修复前发现 bug）
- 原系统 walk-forward 输出 avg_exact_hit=5.0、coverage=1.0（30期全部"5中5"）——**这是指标 bug**：`_single_predict` 返回全部35个号码排序，metrics 用全集算 coverage/exact_hit 恒为100%。
- 真实有效指标 `avg_top_k_hit=1.60`（Top10命中），与随机 1.43 仅差 +0.17——**与逐思路回测的 freq100 结论一致**。
- **已修复**：metrics 改用 Top-K（默认10）集合计算 coverage/exact_hit，修复后 5 期验证 avg_exact_hit=1.0、hit_5=0，指标恢复正常。

## 四、跨球种共性规律（最重要的发现）

> **动量/状态类信号 > 关系结构类信号**

| 类别 | 双色球 | 大乐透 | 结论 |
|---|---|---|---|
| 状态/动量（热延续、冷回补、遗漏、三态偏置、蓝补红） | miss/blue_boost ✅ | freq100/state_bias ✅ | **有效，保留加权** |
| 关系结构（纠缠Lift、图网络、配对、共现、谱嵌入） | entangle/graph ❌ | graph/graph_emb ➖ | **无效，删除或展示用** |
| 复杂时序/概率模型（Markov、Temporal、全融合） | 负效 ❌ | 未显著 | **数据量不足，砍掉或仅参考** |
| 多信号简单叠加 | 中性 | 负效 | **禁止无差别叠加，只融合验证过的信号** |

一句话：**"看状态、看冷热"有效；"看号码关系、堆复杂模型"无效。**

## 五、调整与修复方案（已实施 + 建议）

### 已实施
1. ✅ **修复回测指标 bug**（`src/backtest/walk_forward.py`）：coverage/exact_hit 改用 Top-K 集合，不再恒为 100%。
2. ✅ **重配融合权重**（`config.yaml`）：提升实证有效的 xgboost 0.25→0.28、hsmm 0.10→0.18、bayesian 0.10→0.13；降低无效的 gnn 0.15→0.10、tft 0.15→0.10、catboost 0.20→0.16。

### 建议（下一步）
3. **双色球 fusion 重构**：删除/降权 entangle、group_hot、rebound、pengpai_prior 中的纠缠与组热度分量；融合分量改为 `miss×0.35 + blue_boost×0.25 + transition×0.15 + freq_line×0.15 + 模型×0.10`（权重经滚动回测在线微调）。
4. **大乐透融合重构**：突出 freq100 与 state_bias；图网络（gnn/谱嵌入）从评分降为可视化展示。
5. **模型降维**：双色球删除 Markov/Temporal/Graph 训练（120期不足以支撑），改为"统计信号 + 轻量融合"；大乐透保留 XGB+HSMM 即可，GNN/TFT 设为可选。
6. **引入信号有效性监控**：每期记录各信号 Top-K 命中，滚动更新信号权重（在线学习），让权重跟随行情漂移。
7. **系统定位回归**：PMSF/ZHIHUI 的定位是"状态识别 + 结构约束 + 规则复盘"，号码排序仅作参考——**不要在报告与 UI 中宣称"预测"，而是"多信号一致性的筛选"**。

---

## 六、结论

- 所有"号码预测"思路的 Top10 命中增量都在 ±0.3 以内，**无法实质预测中奖，这是彩票独立随机的本质**。
- 但相对信息量排序清晰：**双色球 = 遗漏回补 > 蓝补红 > 过渡号；大乐透 = 近100期频率 > 三态偏置**。
- **纠缠 Lift、彭湃整体先验乘积、复杂时序/图模型、无差别信号叠加是明确的负贡献**，应当剔除。
- 系统回测指标 bug 已修复，融合权重已按实证校准。
