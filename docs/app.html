自动更新机制：系统通过 GitHub Actions 定时（每日北京时间 21:00 / 22:00 大乐透开奖后）自动执行以下流程：

  1. 从500彩票网抓取最新开奖数据
  2. 对比上期推荐的4组，进行复盘分析（命中数、奖项等级）
  3. 更新中奖台账和统计指标
  4. 重新运行五层系统，优化模型参数
  5. 生成下一期4组推荐
  6. 更新所有JSON数据文件，自动部署到网站

手动更新：在项目目录运行 python scripts/update_data.py 即可手动触发完整更新流程。
