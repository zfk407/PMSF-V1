## 一、频率信号深挖（为什么有用）

### 1.1 窗口调优结果（Top10 命中均值，随机≈1.43）

| 窗口 | 全量 | 同线 |
|---|---|---|
| 20 | 1.36 | 1.28 |
| 30 | 1.49 | 1.39 |
| 50 | 1.38 | **1.54** |
| 80 | 1.49 | 1.49 |
| **100** | 1.48 | **1.53** |
| **150** | 1.32 | **1.60 ← 最优** |
| 200 | 1.45 | 1.45 |
| 指数衰减100 | 1.34 | 1.24 |

**结论**：
1. **同线 150 期等权频率是最优单信号（1.60）**，比全量同窗口高 +0.28。
2. **等权 > 指数衰减**（exp100 全量 1.34 / 同线 1.24 均差）——热号延续是"长期均衡"而非"近期动量"，近期加权反而有害。
3. 当前系统 features.window_long=30 且未拆线——**明显低于最优配置**。

### 1.2 频率为什么有用
- 大乐透号码存在**长期频率惯性**：过去约 150 个同线期内的热点号码，下一期继续出现的概率稳定高于随机。
- 该信号跨窗口稳健（50/80/100/150 同线均 ≥1.49），不是噪声拟合。

## 二、三态偏置深挖（重要修正！）

### 2.1 状态识别分布（100期）
| 判定来源 | A(纠缠热) | B(终止冷) | C(拓展回补) |
|---|---|---|---|
| rule_based | 6 | **74** | 20 |
| HSMM | 5 | **78** | 17 |

**问题**：状态判定严重偏斜，B 态占 74-78%。三态识别区分度差（HSMM 平均持续期 A=1.07/C=1.19/B=5.15，B 态被系统性高估）。

### 2.2 各态下"状态偏置评分 vs 纯频率"Top10 命中
| 状态 | 应用偏置 | 纯频率 | 增量 |
|---|---|---|---|
| A | 1.60 | 1.60 | 0.00 |
| B | 1.18 | 1.60 | **-0.42** |
| C | 0.94 | 1.59 | **-0.65** |

**重大修正**：把三态偏置**直接乘到号码评分上是负效的**（B态-0.42、C态-0.65）。原因：
- B 态（终止冷态）理论应"冷号回补"，但实测 B 态下实际开出的仍是热号偏多（热1.57 > 冷1.34）——"冷态必回补"在大乐透号码层面**不成立**。
- C 态（拓展回补态）偏置冷号加权最重，实测 C 态实际热号远多于冷号（热1.70 vs 冷1.15），方向完全反了。
- **上一轮"state_bias +0.12 有效"的真相**：当时实现是 `偏置权重 × (1 + 频率/10)`，频率项占了主导，偏置本身几乎无贡献。

### 2.3 修正
- 融合内三态贝叶斯修正从强幅度（hot1.3/cold0.7 等）**温和化**（hot1.08/cold0.96 等）——保留极小方向性但不伤害排序。
- 彭湃规则修正（`_pengpai_rule_bias`）**中性化**——实证任何乘法修正都降命中，不再扰动频率主导排序。
- 状态识别保留作"展示/复盘"，不再直接驱动号码评分。

## 三、其他信号深挖

### 3.1 遗漏形态（命中率，35 号均匀≈0.143）
| 遗漏区间 | 命中率 | 判定 |
|---|---|---|
| 0-2 期 | 0.146 | 正常（重号） |
| 3-5 期 | 0.131 | 略低 |
| 6-10 期 | 0.134 | 略低 |
| **11-20 期** | **0.163** | ✅ 显著高（+14%） |
| **21+ 期** | **0.165** | ✅ 显著高（+15%） |

**结论**：长遗漏（≥11期）号码有真实回补倾向，**但与双色球一致**。信息量存在但微弱（Top10 层面不足以弥补对频率排序的扰动，见第五节验证）。

### 3.2 返点分阶（每期命中率）
| 阶数 | 命中率 | 判定 |
|---|---|---|
| 第1阶（上一同线期） | 0.142 | 无效 |
| 第2阶 | 0.126 | 负效 |
| **第3阶** | **0.156** | ✅ 有效（印证"三隔期必出返点"） |
| 第4阶 | 0.134 | 无效 |
| 第5阶 | 0.144 | 无效 |

**结论**：彭湃"三隔期返点"规律被数据支持（0.156），但仅第3阶有效，1/2/4/5 阶无效——**当前系统的"1-5阶指数衰减λ=0.35"应改为只取第3阶**。

### 3.3 双线隔离（Top10 命中）
| 用法 | 命中 |
|---|---|
| 同线频率（正确） | **1.53** |
| 跨线频率（错误） | **1.29** |

**结论**：跨线预测命中掉 **-0.24**。双线隔离公理被强验证——即使同线不提升，**隔离防止了跨线污染**。这是必须保留的防御性规则。

## 四、修正中性化验证（为什么不强加修正）

把遗漏回补+3阶返点乘进同线150频率评分：

| 方案 | Top10 | 增量 |
|---|---|---|
| 纯同线150频率（基线） | **1.60** | — |
| 频率 × 遗漏回补 × 3阶返点 | 1.54 | **-0.06** |
| 逐期胜率 | 优化胜12 平71 负17 | 优化负多 |

**结论**：单看遗漏/返点有信息量（0.16 vs 0.143），但**把它们乘进频率排序反而把高频号挤下去、降低命中**。正确做法是：
- **主评分 = 同线150频率主导**（通过 XGB + 新增 freq_line 融合分量）
- 遗漏回补/3阶返点仅作**次级参考/展示**，不进入乘法修正

## 六、结论（大乐透最终画像）

**✅ 真正有用（保留）**
1. 同线150期等权频率——最强单信号 1.60
2. 双线隔离——防御价值大（跨线-0.24）
3. 长遗漏（≥11期）回补、第3阶返点——有信息量但微弱，作次级参考

**❌ 无用/有害（已修正）**
4. 三态偏置直接调制号码评分——B态-0.42 / C态-0.65（已温和化/中性化）
5. 指数衰减频率、短窗口（20期）——差于等权150
6. 1/2/4/5阶返点——无效
7. 图网络/时序（gnn/tft）——已降权至0.05

**核心规律**：大乐透可验证的信息集中在**"同线长期频率惯性 + 双线隔离"**，其余彭湃/模型因子多为噪声。系统的科学定位应是"频率惯性筛选 + 双线隔离 + 结构约束"，而非"多因子预测"。
